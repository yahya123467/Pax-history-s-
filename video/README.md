# 5,000 Years in 60 Seconds

A 60-second film about the history of civilization, rendered entirely from code.
The night side of the Earth starts dark; cities light up as the year counter runs
from 3500 BCE to today, ending on NASA's real map of the planet's lights.

**Watch:** [`out/five-thousand-years-1080p60.mp4`](out/five-thousand-years-1080p60.mp4) (1920×1080, 60 fps, H.264 + AAC stereo)

## How it is made

- `film/` is a web page whose `renderFrame(t)` draws any frame as a pure function of time.
  - `js/earth.js`: WebGL2 globe (moonlit surface, relief, atmosphere, night lights that switch on by region and year).
  - `js/main.js`: camera, city lights, routes, typography, year and population counters, bloom and grain.
  - `js/script.js`: the script: timing, camera path, captions, labels, routes.
  - `js/cities.js`: about 290 historical cities with the years they rose and fell.
- `scripts/render.mjs` drives headless Chromium, pipes raw frames into x264 and muxes the score.
- `scripts/score.py` synthesizes the original soundtrack (no samples) and syncs chimes to the lights.

## Rebuild

```bash
cd video
npm install                 # map data, fonts, Earth textures
pip install numpy scipy pedalboard
node scripts/cues.mjs       # timing cues for the score
python3 scripts/score.py    # out/score.wav
node scripts/render.mjs --out out/five-thousand-years-1080p60.mp4 --crf 20
node scripts/still.mjs --t 6.1,21,55   # single frames for review
```

Needs Node 20+, Playwright with Chromium, ffmpeg and Python 3. The full render takes
roughly 40 minutes on 4 cores. `--w 1080 --h 1920` renders a vertical cut.

## Sources and accuracy

- City dates are conventional scholarly approximations, rounded. Population figures are
  mid-range HYDE/UN estimates and are labelled as estimates on screen.
- Lights before 1760 are the curated cities. After 1760 they come from NASA's night-lights
  image, switched on by region and brightness: an illustration of spread, not measured data.
- Coastlines, rivers and country shapes: Natural Earth (public domain).
- Earth textures: NASA Blue Marble and Black Marble, via the `three-globe` npm package.
- Fonts: Cinzel, Cormorant Garamond, Inter (SIL Open Font License).
- Music: original, generated by `scripts/score.py`.
